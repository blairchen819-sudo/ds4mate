# Page: 预设管理窗口

> 此文件覆盖 MASTER.md，仅写差异字段。

## 覆盖字段

### 路由
- 触发：菜单栏 → 当前 Profile → 编辑 Profile…
- 容器：NSWindow（非 Sheet，多实例允许）

### 尺寸
- 600 × 400pt（macOS 标准 Settings 风格偏小）
- 圆角：12pt

### 布局
**单栏**：3 列预设卡片网格 + "+ 新建"卡 + 底部工具行

### 组件清单
- `ProfileCard` — 预设名 + 勾选 + 映射摘要 + Edit 按钮
- `NewProfileCard` — 空态卡：SF Symbol `plus.circle` + 「新建 Profile」
- `ProfileActions` — 底部工具行：导入 / 导出 / 删除

### 视觉差异（vs MASTER）
- 卡片：220 × 220pt，圆角 `--radius-md`，bg `--bg-window`
- 激活态（当前使用）：border 2px `--brand-600`，左上角 [OK] 标记
- 映射摘要：最多 3 行 11px `--fg-tertiary` 文字，超过显示 "…"
- "新建"卡片：虚线 border，hover 时变实线 `--brand-400`

### 交互细节
- 点击 Edit → 切换到编辑器（无需新建窗口，复用 §editor）
- 长按 ProfileCard → 弹出 ContextMenu（重命名 / 复制 / 删除 / 设为默认）
- 拖拽 ProfileCard → 交换顺序（仅 V2，V1 用箭头按钮）
- "+ 新建" → 弹出输入框（Profile 名称）→ 复制当前 Profile 内容 → 进入编辑器
